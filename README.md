# 🛍️ ООП-модель интернет-магазина

Привет! Это учебный проект, в котором я на практике разбираюсь с объектно-ориентированным программированием 
(ООП) на Python. Здесь нет сложного бэкенда или базы данных — только классы, которые описывают товары и 
категории для интернет-магазина. Теперь с защитой данных и удобными методами.

## 🎯 Что умеет этот проект?

- **Создавать товары** с названием, описанием, ценой и количеством (`Product`).
- **Группировать товары в категории** с названием, описанием и списком товаров (`Category`).
- **Автоматически считать** общее количество категорий и товаров в системе.
- **Защищать данные** — список товаров в категории и цена товара стали приватными.
- **Добавлять товары** в категорию через специальный метод `add_product`.
- **Просматривать товары** в категории в красивом текстовом формате через геттер.
- **Изменять цену** товара с проверкой на положительность (если цена отрицательная — выводится 
предупреждение и цена не меняется).
- **Создавать товары из словаря** с помощью класс-метода `new_product` (удобно для загрузки из JSON).
- **Избегать дубликатов** — если товар с таким же названием уже есть, количество складывается, а цена выбирается 
максимальная (доп. задание).
- **Загружать данные из JSON-файла** — просто положи файл `data/products.json`, и проект сам создаст объекты.

## 🧪 Как проверить, что всё работает?

```bash
poetry run pytest -v
```
Если увидишь зелёные строки — значит, всё ок. Тесты проверяют создание товаров, категорий, 
добавление, геттеры, сеттеры, класс-метод и загрузку из JSON.

## 🔍 Примеры использования
Создание товара и категории
```python
from src.products import Product, Category

phone = Product("Смартфон", "AMOLED, 128GB", 49999.0, 10)
tablet = Product("Планшет", "10 дюймов, 64GB", 29999.0, 5)

electronics = Category("Электроника", "Гаджеты и устройства", [phone, tablet])
print(electronics.products)
# Смартфон, 49999.0 руб. Остаток: 10 шт.
# Планшет, 29999.0 руб. Остаток: 5 шт.
```
Добавление товара в категорию
```python
from src.products import Product, Category

laptop = Product("Ноутбук", "Игровой", 1500.50, 3)
electronics = Category("Электроника", "Гаджеты", [])
electronics.add_product(laptop)
print(electronics.products)
# Ноутбук, 1500.5 руб. Остаток: 3 шт.
```
Изменение цены (с проверкой)
```python
from src.products import Product

phone = Product("Смартфон", "AMOLED", 49999.0, 10)
phone.price = 45000.0       # цена обновится
phone.price = -1000.0       # выведет: "Цена не должна быть нулевая или отрицательная"
print(phone.price)          # останется 45000.0
```
Создание товара из словаря (класс-метод)
```python
from src.products import Product

data = {"name": "Наушники", "description": "Беспроводные", "price": 5000.0, "quantity": 20}
headphones = Product.new_product(data)
print(headphones.name, headphones.price)
# Наушники 5000.0
```
Загрузка из JSON
```python
from src.products import load_products_from_json

categories = load_products_from_json("data/products.json")
for cat in categories:
    print(f"Категория: {cat.name}")
    print(cat.products)
```
