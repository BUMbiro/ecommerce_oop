# 🛍️ ООП-модель интернет-магазина

Привет! Это небольшой учебный проект, в котором я на практике разбираюсь 
с объектно-ориентированным программированием (ООП) на Python. Здесь нет сложного бэкенда или базы данных — 
только классы, которые описывают товары и категории для интернет-магазина.

## 🎯 Что умеет этот проект?

- **Создавать товары** с названием, описанием, ценой и количеством (`Product`).
- **Группировать товары в категории** с названием, описанием и списком товаров (`Category`).
- **Автоматически считать** общее количество категорий и товаров в системе (без ручного учёта).
- **Загружать данные из JSON-файла** просто положи файл `data/products.json`, и проект сам создаст объекты.

---
## 🧪 Как проверить, что всё работает?

```bash
poetry run pytest -v
```
Если увидишь зелёные строки — значит, всё ок. Тесты проверяют создание товаров, категорий и счётчики.

## 🔧 Как запустить?
```bash
poetry run python main.py
```
Выведется информация о товарах и категориях, которые описаны в коде.

## 🔍 Дополнительное задание (со звёздочкой)
Реализована функция load_products_from_json, которая читает data/products.json и создаёт объекты Product и Category.

```python
from src.products import load_products_from_json

categories = load_products_from_json("data/products.json")
for cat in categories:
    print(f"Категория: {cat.name}")
    for product in cat.products:
        print(f"  {product.name} — {product.price} ₽")
```
Если файл не найден — функция вернёт пустой список без ошибок.
