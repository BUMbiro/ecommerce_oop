# 🛍️ ООП-модель интернет-магазина

Привет! Это учебный проект, в котором я на практике разбираюсь с объектно-ориентированным программированием 
(ООП) на Python. Здесь нет сложного бэкенда или базы данных — только классы, которые описывают товары и 
категории для интернет-магазина. Теперь с защитой данных и удобными методами.

## 🎯 Что умеет этот проект?

- **Создавать товары** с названием, описанием, ценой и количеством (`Product`).
- **Группировать товары в категории** с названием, описанием и списком товаров (`Category`).
- **Автоматически считать** общее количество категорий и товаров в системе.
- **Защищать данные** — список товаров в категории и цена товара стали приватными.
- **Добавлять товары** в категорию через специальный метод `add_product`.
- **Просматривать товары** в категории в красивом текстовом формате через геттер.
- **Изменять цену** товара с проверкой на положительность (если цена отрицательная — выводится предупреждение 
и цена не меняется).
- **Создавать товары из словаря** с помощью класс-метода `new_product` (удобно для загрузки из JSON).
- **Избегать дубликатов** — если товар с таким же названием уже есть, количество складывается, а цена выбирается 
максимальная.
- **Загружать данные из JSON-файла** — просто положи файл `data/products.json`, и проект сам создаст объекты.
- **Красиво выводить информацию** о товарах и категориях через `__str__`.
- **Складывать товары** — магический метод `__add__` считает общую стоимость всех товаров на складе.
- **Перебирать товары в категории** через цикл `for` — благодаря итератору.

## 🔒 Инкапсуляция: защита данных

Теперь важные данные в проекте защищены от случайного изменения:

- **Список товаров в категории** стал приватным (`__products`). Добавить товар можно только через метод `add_product`.
- **Цена товара** стала приватной (`__price`). Изменить её можно только через сеттер с проверкой:
  - если цена положительная — обновляется;
  - если цена <= 0 — выводится сообщение «Цена не должна быть нулевая или отрицательная», и цена остаётся прежней.

### 🧠 Как это работает

```python
from src.products import Product

product = Product("Ноутбук", "Игровой", 50000.0, 5)
product.price = 45000.0   # ✅ цена обновится
product.price = -1000.0   # ❌ выведет предупреждение, цена не изменится
print(product.price)      # 45000.0
```

✨ Магические методы

__str__ — строковое представление
Теперь объекты Product и Category красиво выводятся в консоль:

```python
from src.products import Product, Category

product = Product("Смартфон", "AMOLED, 128GB", 49999.0, 10)
category = Category("Электроника", "Гаджеты и устройства", [product])

print(product)
# Смартфон, 49999.0 руб. Остаток: 10 шт.

print(category)
# Электроника, количество продуктов: 10 шт.
```

__add__ — сложение товаров
Можно складывать два товара, чтобы получить общую стоимость всех товаров на складе:

```python
from src.products import Product

a = Product("Товар А", "Описание", 100, 10)   # 100 * 10 = 1000
b = Product("Товар Б", "Описание", 200, 2)    # 200 * 2 = 400
print(a + b)   # 1400
```
Итератор — перебор товаров в категории
Добавлен вспомогательный класс CategoryIterator и метод __iter__ в Category, 
так что теперь можно перебирать товары прямо в цикле:

```python
from src.products import Product, Category, CategoryIterator

cat = Category("Электроника", "Гаджеты", [
    Product("Ноутбук", "Игровой", 1500.50, 3),
    Product("Мышь", "Беспроводная", 25.0, 50),
])

iterator = CategoryIterator(cat)
for product in iterator:
    print(product)
```

## 📦 Удобное создание товаров
Реализован класс-метод new_product, который создаёт товар из словаря. 
Это удобно при загрузке данных из JSON или других источников.

```python
from src.products import Product

data = {"name": "Наушники", "description": "Беспроводные", "price": 5000.0, "quantity": 20}
headphones = Product.new_product(data)
print(headphones)   # Наушники, 5000.0 руб. Остаток: 20 шт.
```
---
## 🔁 Проверка дубликатов
Если при создании товара через new_product передан список существующих товаров, метод проверит, нет ли уже товара с таким же названием. Если есть — количество сложится, а цена станет максимальной из двух.

```python
from src.products import Product

existing = Product("Смартфон", "AMOLED", 500.0, 10)
data = {"name": "Смартфон", "description": "AMOLED", "price": 600.0, "quantity": 5}
new_product = Product.new_product(data, [existing])
print(new_product.quantity)  # 15
print(new_product.price)     # 600.0
```
## 🔄 Итератор для категорий

Теперь можно перебирать товары в категории с помощью цикла `for`:

```python
from src.products import Product, Category

category = Category("Электроника", "Гаджеты", [
    Product("Мышь", "Беспроводная", 25.0, 50),
    Product("Клавиатура", "Механическая", 80.0, 20),
])

for product in category:
    print(product)
# Мышь, 25.0 руб. Остаток: 50 шт.
# Клавиатура, 80.0 руб. Остаток: 20 шт.
```

from src.products import Product, Category

phone = Product("Смартфон", "AMOLED, 128GB", 49999.0, 10)

# Смартфон, 49999.0 руб. Остаток: 10 шт.
